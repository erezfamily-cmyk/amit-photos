## להמשיך ב־VS Code בכל זמן

כל קובצי המקור וההנחיות נמצאים בענף GitHub שמופיע למעלה; התיקייה המקומית היא רק עותק עבודה.

### עותק חדש במחשב

ב־PowerShell, בתיקייה שבה תרצה לשמור את הפרויקט:

```powershell
git clone --branch design/home-experience-rollout-2026-10-26 https://github.com/erezfamily-cmyk/amit-photos.git amit-photos-experience
Set-Location amit-photos-experience
code .
```

### עותק קיים

קודם בדוק אם יש בו שינויים שלך. אם כן, אל תחליף או תמחק אותם; אפשר לפתוח עותק נפרד לפי הפקודות שלמעלה. בעותק נקי:

```powershell
git fetch origin
git switch design/home-experience-rollout-2026-10-26
git pull --ff-only
code .
```

### תצוגה מקומית

```powershell
npx wrangler dev
```

פתח בדפדפן: `http://localhost:8787/?experience=warm`  
לאנגלית: `http://localhost:8787/?experience=warm&lang=en`

השינוי מכוון להיות opt-in: בלי הפרמטר `experience=warm`, דף הבית נשאר בתצוגה הקיימת. `wrangler dev` מפעיל סביבת פיתוח מקומית; הוא לא מפרסם את האתר.

### לשמור ולהמשיך

אחרי משיכה של הענף, שינויים נשמרים ב־GitHub עם commit ו־push לאותו ענף; ה־PR מתעדכן. לפני push, בדוק `git status` ואת ה־diff. אל תכלול קובצי סודות כמו `.dev.vars`. כדי להתחיל שלב חדש, עדכן את רשימת השלבים במסמך הזה וב־PR המתאים.
