## 3. ממצא מרכזי: מיקסר ערוצים שחור-לבן (בדיקת עומק)

**מסקנה: קיים חלקית — לא כמדריך עצמאי.**

קיים ב-`/camera/color-channels/` (דמו ב', שורות 296-340): סליידרים R/G/B, 4 פריסטים, הסברים דינמיים.

**המגבלה הטכנית:** הדמו הקיים הוא **קירוב CSS בלבד** (`grayscale + brightness + contrast` גלובליים) — לא מיקסר אמיתי per-pixel. אי אפשר לראות בו עור מתבהר ושמיים מחשיכים בו-זמנית.

**מה חסר למדריך עצמאי מעמיק:**
1. דמו canvas אמיתי — `gray = r*wR + g*wG + b*wB` לכל פיקסל
2. הסבר משקולות luminance (Rec. 601/709)
3. הקשר היסטורי — פילטרי צבע בצילום פילם (אדום/צהוב/ירוק)
4. workflow מעשי בלייטרום/פוטושופ (B&W panel, HSL)
5. דוגמאות לפני/אחרי על כמה סצנות (נוף/פורטרט/רחוב)
6. **פער קישור:** מדריך black-and-white מציג את הבעיה ("עגבנייה ועלה → אותו אפור") אבל לא מקשר לפתרון בcolor-channels
